# Government Sandipani Higher Secondary School

Bilingual responsive school website for Government Sandipani Higher Secondary School, Damoh, Madhya Pradesh.

## Run locally

Requires Node.js and pnpm.

    pnpm install
    pnpm run dev

The development server uses port 5173 by default. Set PORT or BASE_PATH when needed.

## Build

    pnpm run typecheck
    pnpm run build

The website includes English/Hindi language switching, dedicated pages, responsive layouts, supplied school photography, gallery filters and lightbox, admissions enquiry UI, notices/events placeholders, SEO metadata, and 404 handling. Official details that have not yet been confirmed remain clearly marked for later updates.
